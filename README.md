# GTCRN
Audio examples for a signle channel speech enhancement model GTCRN.


## UL-UNAS comparisons

[Listen to the UL-UNAS comparisons](ulunas.html), alongside RNNoise and GTCRN on the same ten DNS3 samples. UL-UNAS outputs were generated from the pretrained DNS3 checkpoint in [Xiaobin-Rong/ul-unas](https://github.com/Xiaobin-Rong/ul-unas) at `00f7c700da43d38347f30a6ccebd86fcbc798e07`, using the unmodified model on CPU in float32 evaluation mode. WAV output is PCM_16 at 16 kHz, without normalization.
